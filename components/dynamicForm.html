# DynamicForm 动态表单组件

基于 Element UI 的 Form 组件进行二次封装，提供了配置化的方式来生成表单。

# 功能特性

  • 配置化渲染 - 通过 JSON 配置快速生成表单
  • 栅格布局 - 支持 Element UI 的栅格系统
  • 字段联动 - 支持表单项之间的联动关系
  • 动态校验 - 支持所有 Element UI 的表单验证规则
  • 事件处理 - 支持配置化的事件处理
  • 紧急修复 - 支持通过配置处理紧急问题

# 复杂嵌套示例

支持多层级的复杂嵌套结构，适用于规则引擎、复杂表单等场景。

展示了如何构建一个复杂的规则配置表单，包含多层嵌套、条件组合等。

<template>
  <div>
    <vin-dynamic-form
      ref="dynamicForm"
      v-model="formData"
      :config="formConfig"
      @submit="handleSubmit"
    />
  </div>
</template>

<script>
export default {
  name: 'DynamicFormComplexNested',
  data() {
    return {
      formData: {},
      formConfig: {
        labelWidth: '100px',
        fields: [
          {
            type: 'group',
            label: '规则条件组',
            prop: 'ruleGroup',
            displayType: 'card',
            fields: [
              {
                type: 'select',
                label: '条件类型',
                prop: 'type',
                required: true,
                rules: [
                  { required: true, message: '请选择条件类型', trigger: 'change' }

                ]
              },
              {
                type: 'group',

                prop: 'userConditions',

                gutter: 20,
                defaultSpan: 8,
                fields: [
                  {
                    type: 'select',
                    label: '属性',
                    prop: 'field',
                    required: true,
                    rules: [
                      { required: true, message: '请选择用户属性', trigger: 'change' }
                    ],
                    options: [
                      { label: '年龄', value: 'age' },
                      { label: '性别', value: 'gender' },
                      { label: '城市', value: 'city' }
                    ]
                  },
                  {
                    type: 'select',
                    label: '运算符',
                    prop: 'operator',
                    required: true,
                    rules: [
                      { required: true, message: '请选择运算符', trigger: 'change' }
                    ],
                    options: [
                      { label: '等于', value: 'eq' },
                      { label: '大于', value: 'gt' },
                      { label: '小于', value: 'lt' }
                    ]
                  },
                  {
                    type: 'input',
                    label: '值',
                    prop: 'value',
                    required: true,

                          { required: true, message: '请选择事件A发生次数', trigger: 'change' }

                    type: 'group',

                          { label: '分享', value: 'share' },
                          { label: '评论', value: 'comment' },
                          { label: '收藏', value: 'favorite' }
                        ]
                      },
                      {
                        type: 'select',
                        label: '发生次数',
                        prop: 'occurrence',
                        required: true,
                        rules: [
                          { required: true, message: '请选择事件B发生次数', trigger: 'change' }
                        ],
                        options: [
                          { label: '至少一次', value: 'atLeastOnce' },
                          { label: '从未', value: 'never' },
                          { label: '多次', value: 'multiple' }
                        ]
                      }
                    ]
                  }
                ]
              }
            ]
          },
          {
            type: 'group',
            label: '规则动作',
            prop: 'actions',
            displayType: 'card',
            gutter: 20,
            defaultSpan: 12,
            fields: [
              {
                type: 'select',
                label: '动作类型',
                prop: 'type',
                required: true,
                rules: [
                  { required: true, message: '请选择动作类型', trigger: 'change' }
                ],
                options: [
                  { label: '发送通知', value: 'notify' },
                  { label: '标记用户', value: 'tag' },
                  { label: '触发事件', value: 'trigger' }
                ]
              },
              {
                type: 'input',
                label: '动作参数',
                prop: 'params',
                required: true,
                rules: [
                  { required: true, message: '请输入动作参数', trigger: 'blur' },
                  {
                    validator: (rule, value, callback) => {
                      try {
                        if (value) {
                          JSON.parse(value);
                        }
                        callback();
                      } catch (e) {
                        callback(new Error('请输入有效的JSON格式'));
                      }
                    },
                    trigger: 'blur'
                  }
                ],
                props: {
                  type: 'textarea',
                  rows: 3,
                  placeholder: '请输入JSON格式的参数'
                }
              }
            ]
          }
        ]
      }
    };
  },
  methods: {
    handleSubmit(formData) {
      this.$refs.dynamicForm.validate((valid) => {
        if (valid) {
          console.log('复杂规则配置:', formData);
          this.$message.success('规则保存成功');
        } else {
          this.$message.error('请完善表单信息');
          return false;
        }
      });
    }
  }
};
</script>

# 特点说明

  • 多层嵌套: 支持无限层级的表单嵌套
  • 灵活布局: 每层可以独立配置栅格布局
  • 数据联动: 支持跨层级的数据联动
  • 条件显示: 支持基于条件的字段显示/隐藏
  • 样式定制: 支持卡片式布局和自定义样式

# API

# Props

参数 说明 类型 可选值 默认值
config 表单配置对象 object - -
value/v-model 表单数据对象 object - {}
eventHandlers 事件处理器映射 object - {}

# Config 配置项

参数 说明 类型 可选值 默认值
labelWidth 标签宽度 string - 120px
labelPosition 标签位置 string right/left/top right
size 组件尺寸 string medium/small/mini small
gutter 栅格间隔 number - 0
defaultSpan 默认列宽 number - 24
showButtons 是否显示按钮 boolean - true
submitText 提交按钮文本 string - 提交
resetText 重置按钮文本 string - 重置
fields 表单项配置数组 array - -

# Field 配置项

参数 说明 类型 可选值 默认值
type 字段类型 string input/select/date/radio/checkbox/switch/slider/textarea/group -
label 标签文本 string - -
prop 字段名 string - -
displayType 分组展示类型（仅type为group时有效） string card -
fields 分组内的字段配置（仅type为group时有效） array - -
defaultSpan 分组内字段的默认列宽（仅type为group时有效） number - -
placeholder 占位文本 string - -
span 列宽 number - -
xs <768px 响应式列宽 number - -
sm ≥768px 响应式列宽 number - -
md ≥992px 响应式列宽 number - -
lg ≥1200px 响应式列宽 number - -
xl ≥1920px 响应式列宽 number - -
required 是否必填 boolean - false
rules 验证规则 array - -
props 组件属性 object - -
options 选项数组 array - -
events 事件配置 object - -
visibility 可见性条件 object - -
disabled 禁用条件 object - -
affects 影响的其他字段 array - -

# Events

事件名 说明 参数
submit 表单提交时触发 formData
reset 表单重置时触发 -
field-change 字段值变更时触发 { value, field, formData }
field-input 输入时触发 { value, field, formData }

# Methods

方法名 说明 参数
validate 表单验证 -
resetFields 重置表单 -
clearValidate 清除验证信息 [props]
getFormData 获取表单数据 -
setFormData 设置表单数据 data
