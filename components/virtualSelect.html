# VirtualSelect 虚拟选择器

VinVirtualSelect 是基于 Element UI Select (opens new window) 组件的虚拟滚动增强版本，完全继承了 Element UI Select 的所有功能和 API，同时支持大数据量下的高性能渲染。

TIP

关于选择器的基础用法，请参考 Element UI Select 文档 (opens new window)。本文档主要介绍 VinVirtualSelect 的增强特性。

# 基础用法

基础的虚拟选择器用法。

性能提示

当前示例加载了 0 条数据，但依然保持流畅的交互体验：

  1. 滚动列表观察是否流畅
  2. 输入关键字进行搜索
  3. 选中/取消选中选项

VinVirtualSelect 通过虚拟滚动技术，确保在大数据量下依然保持高性能。

选择数据量: 1000

通过 options 属性传入大量选项数据，组件会自动应用虚拟滚动优化。

TIP

VinVirtualSelect 可以轻松处理大量数据的渲染，而不会影响性能。

  <div class="select-demo">

      <div class="tip-title">

        </ol>
        <p class="tip-highlight">VinVirtualSelect 通过虚拟滚动技术，确保在大数据量下依然保持高性能。</p>
      </div>
    </div>

    <!-- 数据量控制 -->
    <div class="control-panel">

        :min="1000"

<script>
// 创建一个可以在服务器端和客户端都能工作的数据生成函数
function generateDataInMainThread(count) {
  return Array.from({ length: count }, (_, index) => ({
    value: 'value' + index,
    label: '选项 ' + (index + 1)
  }));
}

export default {
  name: 'BasicSelect',
  data() {
    return {
      value: '',
      options: [],
      dataCount: 1000, // 初始数据量
      currentCount: 0,
      isGeneratingData: false,
      worker: null
    };
  },
  mounted() {
    // 在客户端环境中初始化 Worker
    if (typeof window !== 'undefined') {
      try {
        this.worker = new Worker(URL.createObjectURL(new Blob([`
          self.onmessage = function(e) {
            const count = e.data;
            const data = Array.from({ length: count }, (_, index) => ({
              value: 'value' + index,
              label: '选项 ' + (index + 1)
            }));
            self.postMessage(data);
          }
        `])));
        
        // 监听 Web Worker 返回的数据
        this.worker.onmessage = (e) => {
          this.options = Object.freeze(e.data);
          this.currentCount = e.data.length;
          this.isGeneratingData = false;
        };
      } catch (e) {
        console.warn('Web Worker 初始化失败，将使用主线程生成数据', e);
      }
    }
    
    // 组件创建时生成初始数据
    this.generateData(this.dataCount);
  },
  beforeDestroy() {
    // 组件销毁前清理数据和终止 Web Worker
    this.options = [];
    if (this.worker) {
      this.worker.terminate();
      this.worker = null;
    }
  },
  methods: {
    generateData(count) {
      if (this.isGeneratingData) return;
      
      this.isGeneratingData = true;
      
      if (this.worker) {
        // 使用 Web Worker 生成数据
        this.worker.postMessage(count);
      } else {
        // 在主线程中生成数据
        setTimeout(() => {
          const data = generateDataInMainThread(count);
          this.options = Object.freeze(data);
          this.currentCount = data.length;
          this.isGeneratingData = false;
        }, 0);
      }
    },
    handleDataCountChange(value) {
      // 数据量变化时重新生成数据
      this.generateData(value);
    }
  }
};
</script>

# 性能对比

Element UI Select 与 VinVirtualSelect 在大数据量下的性能对比。

性能对比演示 (当前数据量: 0)

选择数据量: 1000
Element UI Select:

    无数据

    常规渲染，数据量受限
    Vin Virtual Select:
    虚拟滚动支持大数据量

    通过对比可以看到，在处理大量数据时 VinVirtualSelect 的性能优势。

    # API

    # Props

    参数 说明 类型 可选值 默认值
    options 选项数据数组 array - []
    value / v-model 绑定值 string / number / array - -
    multiple 是否多选 boolean - false
    disabled 是否禁用 boolean - false
    valueKey 选项对象中值的键名 string - 'value'
    labelKey 选项对象中标签的键名 string - 'label'
    minItemSize 选项的最小高度 number - 34
    beautifyScrollerStyle 是否美化滚动条样式 boolean - false
    dropdownItemsCount 下拉框可见选项数量 number - 6

    # Events

    事件名称 说明 回调参数
    change 选中值发生变化时触发 目前的选中值
    visible-change 下拉框出现/隐藏时触发 出现则为 true，隐藏则为 false
    remove-tag 多选模式下移除tag时触发 移除的tag值
    clear 可清空的单选模式下用户点击清空按钮时触发 -
    blur 当 input 失去焦点时触发 (event: Event)
    focus 当 input 获得焦点时触发 (event: Event)

    # Slots

    插槽名 说明
    label 选项的自定义内容，参数为 { item }
